# 事现鉴 · 他验操作工具包（大白话说明书）

## 这是什么？
前面咱们做了一份"整个对话的可验证档案"（SXJ-verification-ledger.md 等）。
这份档案是**给别人检验用的**。但你（白玺）要去操作"让他验、收结果、看够不够发布"，
不能每次都手动翻文档、数有几家通过了。

所以这个工具包，就是给**你**准备的一个**遥控器**：
- 你不用懂代码、不用懂原理；
- 你说一句"发件"，它就帮你把要发的文件列好；
- 别人把检验结论交回来，你往里一塞，它就自动记、自动数；
- 数到 ≥2 家成功，它就提示你"可以发布了"。

---

## 两个用法，挑你顺手的

### 用法 A：网页控制台（推荐·零基础）
双击打开 `sxj-verify/console.html`（用浏览器打开就行）。
- ① 看到要发出去的文件清单 → 点"复制文件清单"
- ② 看到他验进度条（几家成功 / 门槛 2 家）
- ③ 别人回执粘进来 → 点"录入回执"
- ④ 有回执模板可一键复制给外部 agent
- ⑤ 门槛到了点"标记已发布"

> 注意：网页版记录存在你浏览器本地（localStorage），换电脑不自动同步。
> 真正"落盘存档"请用下面的命令行工具。

### 用法 B：命令行（类 API 接口，给会跑代码的人 / 外部 agent 用）
在 `sxj-verify/` 目录下，运行这几条"口令"：

| 你说的 | 实际命令 | 它干啥 |
|---|---|---|
| 打包发件 | `python verify_cli.py init` | 列出送检包 + 档案指纹 |
| 先自检 | `python verify_cli.py selfcheck` | 本平台跑 A01-A13，落一份自检回执 |
| 收回执 | `python verify_cli.py submit --file 回执.json` | 录入一份外部 agent 回执 |
| 看进度 | `python verify_cli.py status` | 显示几家成功、够不够发布 |
| 宣布发布 | `python verify_cli.py release --confirm 白玺-发布` | 决定层拍板，档案翻"已发布" |

> 外部 agent 也可以直接跑 `submit` 把回执交回来（前提是回执里的档案指纹对得上）。

---

## 外部 agent 的回执长啥样？
看 `receipt-schema.json` —— 一张标准"回执单"：
- `agent_id`：他是谁
- `verdict`：PASS（通过）/ CONDITIONAL（有保留）/ FAIL（有矛盾）
- `ledger_sha256`：送检档案的指纹（对不上就拒收，防狸猫换太子）
- `assertions`：A01-A13 逐条 pass/fail
- `rights_opinion`：对 R1-R6 本轮权利的态度
- `dept_stance`：承接部门 / 组建新部门 / 拒绝承担（三选一）
- `signature`：把上面信息算个摘要，绑定到档案

---

## 发布门槛（写死在工具里）
**≥2 家冷方(无语料)独立平台 agent 判定成功（PASS 或 CONDITIONAL），且无互证矛盾**
→ 由决定层（白玺）运行 `release --confirm 白玺-发布` 正式发布。

## 防作弊设计
- 每份回执必须回填送检档案的 SHA256，错了直接拒收 → 防止拿旧版/篡改版来验；
- 本平台自检回执**不计入**外部 2 家门槛，只是给你自己对照；
- 发布必须决定层口令，PM / 任何 agent 都不能单方面宣布。

## 新增：多智能体交互协议 v1.0（2026-08-02）

上面讲的是"**怎么收别人的检验结论**"。但收上来之后，多家 AI 怎么**一起讨论、互相质疑、算出结论**——
这套"开会规矩"过去是口头的，现在写成了正式协议。

| 文件 | 是什么 | 给谁看 |
|---|---|---|
| `SXJ-MAIP-v1.0.md` | **协议正文**。第零章是大白话导读，不懂技术也能读 | 白玺 / 所有参与方 |
| `maip-v1.0-schema.json` | 机器可读消息格式（JSON Schema） | 外部 agent / 程序 |
| `maip-example-round.json` | 一整轮交互的完整样例（case_D1 耿同学归类） | 想照着写的人 |
| `maip_check.py` | **裁判程序**，零依赖，自动卡门槛 | 谁都能跑 |
| `SXJ-MAIP-v1.0.sha256` | 协议套件指纹清单 | 防篡改 |

一句话跑起来：

```bash
python maip_check.py maip-example-round.json
```

它会告诉你：这一轮算不算数、有没有人违规、够不够格进入下一步、哪些事**必须由你（白玺）拍板**。

**这套协议解决的四个老毛病**：只写总结不反驳 → 强制每轮至少一条实质质疑；说"通过"却不说几成把握 → 置信度成为必填项；讨论越久越同质 → 盲评 + 功能互补角色 + 反跟风信任衰减；谁能拍板不清楚 → 六项保留事项写死为人类专属。
